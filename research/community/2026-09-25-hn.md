Sid, Alex, Ketan, and Milan / [`devdotfast/whiteboard`](https://github.com/devdotfast/whiteboard) (posted ~17:21 UTC yesterday). Agent-review IDE, not a model release — an open-source desktop app "where humans and agents can architect software together," plugging into Claude Code, Codex, and similar harnesses and giving the agent an SDK to draw on an in-app canvas. Built on CodeOSS so a click on a sequence diagram, ER diagram, or a quote from the agent's trace jumps to the underlying code with VS Code keybindings and LSP. Semantic / AST-aware diff viewer they wrote in Rust ([`devdotfast/diffr`](https://github.com/devdotfast/diffr)): large added functions summarized as pseudocode; unit tests and large docs collapsed; WASM plugin system. Decision Log lets agents query and link their own traces so a reviewer can see which requirements were implemented and which decisions the agent made autonomously. Named users they stamp: Salesforce and Modal, typically as a review tool for architecture / spec-level changes — own-agent prototypes get a Whiteboard session; other people's PRs escalate from Greptile-class auto-review when the change needs human judgement. Why they built it: four college friends who quit tech-lead jobs "right before agentic coding became industry standard," then watched "cognitive debt" (Geoffrey Litt, "Understanding is the new bottleneck," 2 July 2026) accumulate as PRs merged without their understanding. Hosted web version they say will eventually charge companies for trajectory storage and multiplayer reviews; everything stays self-hostable. Storage: the agent holds no secrets; the form mints a Vercel Blob upload token scoped to one path for three hours. Demo reels they ship untouched: NVIDIA, TypeSafe Jev, OpenComputer, Linear, and a prompt-only Infera clip. Idea they credit: Deedy's post on Opus 5.5 and instructional video — the model writes the film as code, and code renders the same every time.
