- [Factoring RSA 260](https://news.ycombinator.com/item?id=49633534): new since 2026-09-09 22:34 — Eric Lu / Cognition (57/7, posted ~20:16 UTC, newly on the front page). - [Training a 3.8B LLM to 0.384 CORE for $998](https://news.ycombinator.com/item?id=49637435): new since 22:34 — Hugo Vergnes / little-lm (25/2, posted ~02:04 UTC). Solo nanochat-inspired pretrain: Llama-style 3.848B (RMSNorm, RoPE, GQA 24/8, relu², QK-norm, logit softcap, ResFormer value embeddings) on 65.3B ClimbMix tokens, 8× B200, 43 hours, CORE 0.384. Same ~$1,000 envelope as nanochat d32 (0.310). Recipe: trapezoidal LR, Muon on matrices / AdamW elsewhere, FP8 + vocab pad to 50,304, fused linear CE. The 1024-ctx run scored 0.338 because three CORE tasks (SQuAD 10-shot, BoolQ, language-ID) were almost entirely cropped; 2048-ctx recovered SQuAD 0.000 → 0.311 and BoolQ 0.513 → 0.710 and accounts for most of the headline jump. Newest cheap-pretrain / measurement-hygiene thread.
