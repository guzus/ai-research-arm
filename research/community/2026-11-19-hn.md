(1) Hawking–Page at weak coupling. 2003 Aharony / Marsano / Minwalla / Papadodimas / Van Raamsdonk calculation never finished for N=4 super Yang–Mills (a simpler cousin was done in 2005). Vendor page: abrupt (first-order) transition at both weak and strong coupling. Preprint abstract: the sign of the quartic Polyakov-loop coefficient b, which first appears at three loops, decides; b = −1.48×10⁻³ λ² (λ the ’t Hooft coupling); “The transition is first order.” Body eq. (64): g⁴ = λ²/256π⁴ and b = −1.481×10⁻³ λ²; eq. (6) b = −36.94(1) g⁴ from g⁴[−31.057(5) + 2.6339×(−2.234(3))]; three-loop q₄ would have to be +11.8 to flip the sign. Hamiltonian computation; almost every number obtained two independent ways; reproduces the two-loop Hagedorn temperature from integrability and exact closed-subsector results. Does not show the first-order line continues unbroken to strong coupling. Independent physicist later reached the same answer by a different method. (2) Spinless modular bootstrap. Hellerman 2009 ceiling M₁ ≤ c/6; Hartman / Mazáč / Rastelli analytical c/8.5; numerics ~c/9.1. Vendor page: exact Λ ≈ 9.1266, and this version of the method cannot by itself reach c/12. Preprint abstract / Theorem 1: Λ_V = 12π²/(π² + 4 arcsinh² 1) = 9.1266340, with x∗₁ := arcsinh(1)/π = 0.2805499; no linear functional in a class containing all finite combinations of derivatives improves on c/Λ_V by more than O(c^{1/3} log^{2/3} c); explicit functional Δ₁ < c/Λ_V + 0.483 c^{1/3} + O(1) for large c; numerics to c = 2048. Spectral-curve method; one half of the optimality half follows an OpenAI sphere-packing proof; an earlier Claude agent failed in 61 parallel attempts; two other agents independently reached the same answer.
