- AI is forcing us to pay off 40 years of technical debt: IEEE Spectrum frames the PHP2Shell vulnerability as old web-stack debt that AI-assisted discovery is now making expensive. The 647-comment thread is the largest AI discussion on the page. - https://news.ycombinator.com/item?id=50364336
- Kimi K3.1 Pro: Moonshot open-weighted a 2.8T-parameter MoE (104B active, 1M context, natively multimodal). Vendor table: Terminal-Bench 4.0 65.7, SWE Marathon v1.1 51.7, HLE-Full w/ tools 70.0, GPQA-Diamond 94.2, all at max effort. These are lab-reported numbers. - https://news.ycombinator.com/item?id=50366999
- Ripple-65B Preview: Ricursive Intelligence (US) claims a dense 65B trained from scratch on 12T tokens for $32M, 80.52 on TerminalBench 2.1, and 1.4M RL rollouts. It positions that as US open-weight SOTA on agentic coding vs Reflection Beam 501B (80.1). Vendor-reported; the model is on Hugging Face, Together, GMI Cloud, and OpenRouter. - https://news.ycombinator.com/item?id=50369925
- OpenAI acquiring Pierre: Official post says Pierre built Code Storage plus the Trees/Diffs libraries already in the Codex app. OpenAI wants Git workflows that fit parallel agent work; Pierre's OSS stays open, and the deal still needs regulatory close. - https://news.ycombinator.com/item?id=50366863
- A thousand fewer paths to root: OpenAI's cyber pipeline, using an upcoming cyber model, dynamically reproduced 1,724 Linux kernel vulns and generated 948 working LPE exploits at $1.2M API cost (~$1,279 per LPE). Human researchers still review before reporting. - https://news.ycombinator.com/item?id=50372929
- Provable inference (Anthropic): FlashProve is a zkSNARK prototype that proves a response came from committed weights. On Llama 4 Maverick 400B MoE (4-bit), one H100 proves ~110 tok/s with ~19 MB proofs per 1,024-token request, about 70-95x vLLM GPU time. Code, Lean proofs, and a C++ verifier are Apache 2.0. - https://news.ycombinator.com/item?id=50368626
- Ask HN agentic setup: 185 comments on paid subscriptions, local/API models, coding harnesses, and swarm tools. A snapshot of what HN is actually running, not a product launch. - https://news.ycombinator.com/item?id=50366117
- Images 2.6: OpenAI says image gen is 50% faster, adds GIF animation, and ships GPT-Image-2.6 Flare (as fast as 6s at low quality) and Sunburst in the API. Claimed volume: 4 billion images/week across ChatGPT, Codex, and the API. - https://news.ycombinator.com/item?id=50372945
