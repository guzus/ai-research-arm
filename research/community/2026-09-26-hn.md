- [Plan mode is dead](https://news.ycombinator.com/item?id=49840054): new since 2026-09-25 23:19 — Ayman Nadeem / [aymannadeem.com](https://www.aymannadeem.com/artificial/intelligence,/developer/tools/2026/09/24/plan-mode-is-dead.html), dated 24 September 2026 (187/179, posted ~03:59 UTC yesterday) and the **most-commented *new* item on the page** (179 vs Copilot's 93 and Sahai's 24). It sat off-page through all four of yesterday's fetches and climbed on overnight. Agent-tooling / process essay, not a model release — a post-mortem of **Nuanced**, the desktop coding app she built around first-class plan documents after watching Claude Code / Conductor / Codex generate code faster than she could hold a mental model. Load-bearing frame: plan modes used to do two jobs — specify instructions precisely enough for an agent, and help humans understand what they were building — and #1 is "rapidly becoming obsolete as models get better" while #2 still matters, but a persistent spec is the wrong abstraction once you run agents in parallel. Four misses she stamps: they conflated planning with a plan (early users had "surprisingly little appetite" for the spec); models got good enough at exploring a repo that each reliable autonomous decision was "one fewer decision that needed to be surfaced"; AI-generated specs were "painful to read," and the Spec Tour they bolted on only added more text; the chat → disambiguate → generate spec → review → revise → approve → implement waterfall forced users to "prematurely finish thinking." New loop she names: **understand → act → inspect → clarify → adjust → act again**, with planning still happening inside the loop but not as an artifact called "the plan."
