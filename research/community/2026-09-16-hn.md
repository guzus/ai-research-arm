- [Learning to solve hard problems in RL for LLMs by never giving up](https://news.ycombinator.com/item?id=49717280): jumped off the 22:54 under-10 filter (7 → 62/0) and is now the #8 AI story. Michael Noukhovitch with Hamish Ivison, Nathan Lambert, and Aaron Courville, dated 15 September 2026 (posted ~19:07 UTC); paper [arXiv 2609.13443](https://arxiv.org/abs/2609.13443). Load-bearing claim: the **Matthew Effect** in RL for LLMs — "RL improves performance on a task in proportion to a model’s initial competence—making easy tasks easier while hard tasks often remain difficult." On Olmo 3.1 RL-Zero Math, an AIME-2025 curve that looks like "math got better" is mostly easy items (initial pass@1 ~22.7%) going from somewhat-solved to mostly-solved; items with initial pass@32 = 0 mostly stay at 0. Same shape on Deepcoder / DeepSWE. Cause is not "just sample a larger `k`": on GSM8k Platinum with Qwen 2.5 0.5B Instruct, `k=4` beats `k=32` on hard items because large `k` keeps rare incorrect easy solutions in the batch after ~200 steps (signal *efficiency*, not only signal loss). **Never Give Up (NGU):** start with small `k`; if the prompt is solved, train; if all completions are wrong, with probability `p` put it back and sample another `k`, training on the whole `k × rounds` group when a solve appears (geometric, expected `k / (1-p)` if never solved). On GSM8k, `k=4` + `p=0.9` beats every fixed-`k` GRPO, especially on the extra-hard subset. Scale: DeepScaler + Qwen 3 4B (~120 H100 hours) improves the hardest AIME + BRUMO 2025 slice over GRPO `k=16`; on Manufactoria code RL, NGU keeps pushing past the 7/12-test plateau until some problems pass all tests. Plasticity is not the cause: a stagnant 6,000-step checkpoint recovers under either an all-tests reward or per-test NGU. Limitation they name: NGU wastes time if the task is almost all hard problems, and early samples go more off-policy. Newest training-method / "the average hid the hard items" thread — the RL-for-LLMs counterpart to r/MachineLearning's still-hot `RSI is not happening` paper, now sitting under Apple Reference Image.
