### Notable Discussions

- **Lost my phone at the office. Claude suggested tracking Bluetooth signal
  strength**: The day's top-scoring AI item (252 points, 183 comments) and
  again the clearest signal for what "AI in the office" looks like when it is
  not about replacing work. Claude proposed using the phone's own crowdsourced
  Bluetooth tracker to triangulate a lost device, and the thread turned into a
  general brainstorm of genuinely useful, low-stakes model suggestions built
  on device APIs rather than text generation. It is the front page's running
  counterweight to the "AI coding discourse" threads: capability people reach
  for naturally rather than performatively —
  [link](https://news.ycombinator.com/item?id=49215786)

- **Message your other Claude Code sessions**: Anthropic productized
  cross-session messaging for Claude Code — parallel agent runs can hand
  messages to one another, turning independent sessions into a coordinated
  team. The HN commenters connect it to the emergent-agent-coordination
  threads of the week: the pattern Anthropic is shipping as a feature is the
  same "agents coordinating with each other" behavior that security timelines
  keep surfacing as a risk. Productization of agent-to-agent messaging is
  moving faster than the safety discussion around it —
  [link](https://news.ycombinator.com/item?id=49222824)

- **ChatGPT starts blocking direct requests to copy an author's style**:
  Ars Technica reports ChatGPT now declines "write like author X" requests,
  though it "may capture a similar feeling" — a policy-and-enforcement
  middle ground between outright style mimicry and usable assistance. The
  discussion centers on how style-guardrails are actually enforced (prompt
  filters, watermarking, refusal heuristics), whether "a similar feeling"
  still lands in legally grey territory, and the trade-off against the
  legitimate use cases (fan writers, pastiche, genre work) that get
  collateral damage —
  [link](https://news.ycombinator.com/item?id=49227718)

- **TheoremDB · A public workspace for machine mathematics**: A small but
  notable listing (16 points, no comments yet) for TheoremDB, a public
  workspace for machine mathematics — the shared corpus + tooling end of
  formalization and automated theorem proving. Worth logging as early signal
  that the formal-math infrastructure layer (datasets, proof-repair, agent
  harnesses) is maturing into a shared-tooling market —
  [link](https://news.ycombinator.com/item?id=49227505)
