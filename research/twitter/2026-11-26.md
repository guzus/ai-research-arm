### Quick hits
- **⚠ GPT-6.2 Astra tops SemiAnalysis's GDPx leaderboard at 19.3%.** Claude Fable 5.2 is second at 16.4%. Gemini 4 Neon, the model most developers have been praising this week, comes sixth at 10.1%. Even the top score is under 20%, so the benchmark is far from saturated. This snapshot only has the first post of the nine-post thread, so the task set and scoring method aren't available here. [@SemiAnalysis_](https://x.com/SemiAnalysis_/status/2125743598587003170)
- **Polymarket now lists markets on what it will cost to rent H100, B200 and B300 GPUs, with expiries out to 2028.** CEO Shayne Coplan calls it "a yield curve for the cost of compute": forecast $/hour prices at each expiry for each chip, with more chips and terms to come. Until now there has been no public forward market for GPU rental prices. [@shayne_coplan](https://x.com/shayne_coplan/status/2125653367640805799)
- **Karpathy: Opus 5.5 spent 7 hours writing 45K lines of code to turn US public data into a Civilization-style map.** It pulled in 31 sources, including Census, BEA, BLS, EIA, NOAA, USGS, FAA, FEMA and CDC, and fitted them onto one 25 km hex grid. The data becomes game terms: GDP is gold yield, and a city's real industries become its districts. It's a showcase project rather than a benchmark, but it shows an agent working for hours over many messy sources. [@karpathy](https://x.com/karpathy/status/2125779541952246039)
- **The KITP collaboration will release all the materials OpenAI gave it,** including work on whether Yang-Mills theory with massive fermions exists and on the SU(5) theory, says @danintheory, one of the collaborators. This is the physics side of the labs' recent wave of math and science results. Expect outside physicists to start checking the work once the files are public. [@danintheory](https://x.com/danintheory/status/2125694659615977619)
- **Google is promoting its open-source Gemini API CLI as an easy way for any coding agent to use Gemini Neon and other Gemini models.** It needs only an API key. Logan Kilpatrick posted the reminder as Neon picks up strong reviews from developers. [@OfficialLoganK](https://x.com/OfficialLoganK/status/2125681386388422775)
