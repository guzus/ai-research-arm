      <p><strong>Evidence:</strong> The <a href="https://x.com/SemiAnalysis_/status/2100027188393189711">01:01 UTC thread</a> is unusually specific about causation, which is what makes it worth taking seriously. The gains come from UMBP's integration into SGLang as a KV offloading backend: HiCache previously sat between HBM and the external DRAM KV store as a per-rank host-side L2 buffer, so every load and offload took an extra copy, the L3-to-L2 fetch was not pipelined with compute, and under MLA with tensor parallelism each rank replicated the same KV across PCIe and host memory while making eviction decisions on local information only. UMBP replaces that with a direct, layer-wise pipelined HBM-to-DRAM path into a single shared per-node pool — removing the copy and the stall, deduplicating replicated KV, and making placement and eviction global across DP ranks. That is a software story, which matters: it is reproducible by anyone running SGLang, and it does not depend on trusting AMD.</p>

### 🚩 Skeptic's corner
- SemiAnalysis's claim that Vera Rubin NVL72 delivers ~67× GB300 throughput per dollar is SLO-bound (170 tokens/s) and arrives with no methodology in-thread. A 67× per-dollar jump in one generation is not a general-purpose performance claim, and the figure should not be quoted without the SLO attached ([@SemiAnalysis_](https://x.com/SemiAnalysis_/status/2100079531923038659)).
- TypeSafe AI's Jev decision model picked up another amplification round with the speed and cost multiples drifting — now "20–200× faster and 40–400× cheaper" at $0.042 per million input tokens ([@kimmonismus](https://x.com/kimmonismus/status/2100057080698950042)).
