The gains come from UMBP's integration into SGLang as a KV offloading backend: HiCache previously sat between HBM and the external DRAM KV store as a per-rank host-side L2 buffer, so every load and offload took an extra copy, the L3-to-L2 fetch was not pipelined with compute, and under MLA with tensor parallelism each rank replicated the same KV across PCIe and host memory while making eviction decisions on local information only. UMBP replaces that with a direct, layer-wise pipelined HBM-to-DRAM path into a single shared per-node pool — removing the copy and the stall, deduplicating replicated KV, and making placement and eviction global across DP ranks. That is a software story, which matters: it is reproducible by anyone running SGLang, and it does not depend on trusting AMD.</p>
