**Cycle summary**: Z.ai (Zhipu) launched GLM-5.4, its first flagship built as a loop transformer that runs the same weights twice per pass, with vision added. It is live only in Z.ai Chat and the GLM Coding Plan; the public API waits on a safety evaluation and no weights date is set.
