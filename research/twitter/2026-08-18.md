### Quick hits
- Claude Code CLI now uses 2× less CPU at p99: Bun's garbage collector was firing on a fixed timer and stealing CPU mid-turn, and now waits for process idle — an unusually specific root cause for a perf note ([@ClaudeDevs](https://x.com/ClaudeDevs/status/2089509659090780193), 00:28 UTC).
- Sakana AI's Namazu, built on Kimi K2.6, went live on OpenRouter — a specialised model reaching third-party inference distribution rather than staying inside Sakana's own chat product ([@OpenRouter via @hardmaru](https://x.com/hardmaru/status/2089523613510914118), 01:23 UTC).
- Replit added black-box penetration testing for Replit-built apps, testing deployed apps the way an external attacker would rather than scanning source ([@Replit via @amasad](https://x.com/amasad/status/2089524822501908598), 01:28 UTC).
- SemiAnalysis published a TPU interconnect thread tracing Google's ICI topology from the 2D torus of TPUv2 to the 3D torus of TPUv4/v5p, and argues a 6D torus would cut worst-case diameter on a 4,096-chip cluster from 24 hops to 12 while multiplying bisection bandwidth — at the cost of far more optics and OCS capacity ([@SemiAnalysis_](https://x.com/SemiAnalysis_/status/2089472651521626622), 22:01 UTC). The visible fragments do not establish whether 6D is shipped or modelled.

### 🚩 Skeptic's corner
- An unattributed harness called "J-Space" is credited with lifting DeepSeek V4 Pro 0813 past Fable 5 and Opus 4.8 on several agentic and coding benchmarks — Terminal Bench 87.9 → 90.1, NL2Repo 61.5 → 73.4, CyberGym 83.3 → 86.8, DeepSWE 62.7 → 72.0, Toolathlon 74.1 → 79.5 ([@kimmonismus](https://x.com/kimmonismus/status/2089488440089788587), 23:03 UTC). The relay itself says "someone has combined" — no author, no paper, no repository, and no primary post appears anywhere in this snapshot despite the claim trending. The deeper problem is the comparison, not the provenance: a model-plus-harness score is being ranked against bare-model scores for Fable 5 and Opus 4.8, which are not running the same scaffold. Treat the deltas as a harness result, not a model result, until the harness is named.
- A parallel claim that scaling self-verification lets DeepSeek V4 Flash beat Claude Fable 5 on Terminal-Bench 2.1 at 11× lower cost circulated in the same window ([@jackyk02 via @arankomatsuzaki](https://x.com/arankomatsuzaki/status/2089484352342409558), 22:47 UTC). Same structural caveat: extra inference-time verification passes against a single-pass baseline is a compute-budget comparison dressed as a capability comparison, and the "11× cheaper" figure only holds if the verification passes are counted in it.
