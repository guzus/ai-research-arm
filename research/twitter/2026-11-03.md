# Twitter/X AI Pulse — 2026-11-03

## 06:00 UTC

**Cycle summary**: Replit published a security advisory urging companies to run AI coding agents in managed cloud environments instead of on employee laptops, citing Bloomberg's report that Goldman Sachs has restricted most staff from AI coding tools such as Claude Code. Separately, the small Qwen model that GPT-6 Astra repaired by editing its weights is now on Hugging Face, and a rebuild from the published logs scored 51.0% on MATH-500, slightly above the 48.1% the researchers reported.

      <p><strong>Counter / contradicting:</strong> Rebuilding from the logs shows the result can be recreated, not that it is valid. Any flaw in how the original evaluation was set up would carry over to the rebuild. The baseline was a degenerate 7.9% caused by repetition loops, so much of the gain may come from removing a single failure mode rather than adding general capability. A 2.9-point gap between two runs is normal variation from decoding settings.</p>
