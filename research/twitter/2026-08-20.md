      <p><strong>Counter / contradicting:</strong> The security framing is mine, not Anthropic's, and it should be discounted accordingly — this shipped as a routine product update, and a domain allowlist is a coarse control. It bounds which hosts the agent may reach; it does nothing about what the allowed hosts say, so a prompt injection served from a permitted domain passes straight through. It covers two server-side tools, not MCP servers, custom tools or shell access, which is where most real agent reach lives. And nothing in the announcement indicates a default: an opt-in allowlist protects the deployments whose owners already modelled the threat. The engagement split inside the same thread is its own finding — the Concise output-style post two hours later drew 1,272 likes against 166 for domain controls, which is a fair proxy for how much of the developer audience is currently buying ergonomics versus perimeter.</p>

Treat the readout as real and the AI framing as unsupported until someone names the system and the step it performed.
