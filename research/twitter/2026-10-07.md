If the result holds, it would still be a real theoretical milestone, because n log n had been widely conjectured to be optimal. ### 🚩 Skeptic's corner
- **"OpenAI's release includes the quasi-Riemann hypothesis and Hilbert's tenth problem."** The new support for this claim, flagged in yesterday's 22:00 brief, is a post by [@ereliuer_eteer](https://x.com/ereliuer_eteer/status/2107618065869574208) (933 likes). It quotes Opus 5.5's reading of the family titles in the repo, for example family 003 claiming a zero-free half-plane Re s > 7/8. A family title is a claim about what a manuscript says, not a checked proof. Also, Hilbert's tenth problem was resolved in 1970, so any "family 004" result has to be about some variant. No mathematician has corroborated either result.
- **"A developer used Opus 5.5 to recreate seven Adobe apps, including Photoshop, as free open-source alternatives."** The relay by [@kimmonismus](https://x.com/kimmonismus/status/2107618163726921853) itself says these are early versions and that the Photoshop clone is not yet ready to use. Public repos show that code exists, not that it matches Adobe's features.
