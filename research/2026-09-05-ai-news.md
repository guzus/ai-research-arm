## Research Papers

Saturday’s arXiv feeds were empty (`skipDays` Saturday/Sunday). These are from the September 4 daily build and were not in yesterday’s five-paper list.

**HookPry: lifecycle-hook updates are a cross-harness supply-chain RCE** (`2609.03884`). Pengxun Li, Litian Zhang, Jianwei Hou, and coauthors bind attacker-chosen shell commands to plugin lifecycle events (session start, tool calls, file edits) that the LLM never sees. Under a threat model that controls only marketplace metadata and hook config, HookPry compromised **7/7** evaluated harnesses across 25 harness/backend pairs and 1,000 end-to-end runs; **77.0%** of runs produced oracle-confirmed effects, peaking at **92.5%** on Hermes, with zero runs explicitly blocked by the model. Microsoft Defender recall was **0%**; the union of three static defenses still missed **47.5%** of malicious artifacts. The authors say they disclosed to all affected vendors. ([arXiv](https://arxiv.org/abs/2609.03884))

**SWE-Gate: 221 of 644 functionally passing agent patches fail the review spec** (`2609.04167`). Xin He, Yanlin Wang, Mingwei Liu, and coauthors build 303 repository-level repairs across 75 Python repos, each with separate functional tests and review-constraint tests mined from real PR comments. Across four LLM backends on one coding-agent scaffold, functional-only scoring overstates accept-ready work: 221 of 644 patches that pass the tests fail the review gate (backward compatibility, exception semantics, repo conventions). Code and data: [github.com/DeepSoftwareAnalytics/SWE-Gate](https://github.com/DeepSoftwareAnalytics/SWE-Gate). ([arXiv](https://arxiv.org/abs/2609.04167))

**Terminal-Universe: 37.3k executable terminals reconstructed from public agent traces** (`2609.04148`). Qwen / Alibaba and Tsinghua authors (Wu, Zhang, An Yang, Fei Huang, Dayiheng Liu) replay file ops from existing trajectories, complete missing files, then synthesize breadth (cross-workspace) and depth (multi-round user-agent) tasks. SFT of Qwen3.5-27B on the corpus lifts Terminal-Bench 2.1 by **11.9** points and EvoCode-Bench v2 MT@4 by **13.8**. ([arXiv](https://arxiv.org/abs/2609.04148))

**Interface-induced trajectory censoring can zero a tool-call leaderboard** (`2609.03966`, draft dated September 3; announced in the September 4 drop). Wenbo Wang holds weights, cases, decoding, and seeds fixed and changes only the serving adapter: the same model scores **0.00** or **0.96 / 0.19** on BFCL v4 (simple_python / multi_turn_base). A 2×2 over chat template and parser puts the entire effect in the interaction. On τ-bench the same swap moves server-parsed calls from **0 to 636**. Inside verl’s AgentLoop at 7B, 45 of 115 generations carry a complete call and **0** are accepted. A 98-line preflight catches every silent failure in the study. ([arXiv](https://arxiv.org/abs/2609.03966))

**Microsoft named its developer Windows SKU Project Zenith.** The Verge, dated September 4 (10:44 AM UTC), says the SKU is aimed at machines with **64GB+** unified memory so developers can run **30B+** parameter models locally and unmetered. Logan Iyer (CVP, Windows platform and developer) said devices ship with a preconfigured Windows setup plus VS Code, GitHub Copilot, PowerToys, WinAppCLI, and Windows Dev Skills; File Explorer shows extensions, hidden files, and full paths, long paths are on, and Start-menu tips are off. AMD announced the first Zenith device at IFA: a mini-PC on Ryzen AI Halo. More silicon variants are “coming months.” ([The Verge](https://www.theverge.com/news/990051/microsoft-project-zenith-windows-developers))

**Ugreen launched HomeAgent at IFA: a local NAS + NVR + on-device assistant.** The Verge, dated September 4 (9:41 AM UTC), lists three hubs: HA100 (early-bird **$899**), HA100 Pro (rising to **$2,999**), and MasterAgent MA100 on an Nvidia Jetson Thor T5000 at **$9,999** (Ugreen cites up to 2,070 TFLOPS). The voice assistant is Uliya. Kickstarter is October; Ugreen says list prices will roughly double after. Matter is the interop layer (lights, switches, sensors, curtains in phase one). Push notifications and remote camera viewing still need the internet; cloud Uliya is optional. Anker launched a similar Eufy MindBase at the same show. ([The Verge](https://www.theverge.com/tech/990006/this-nas-company-wants-to-run-your-local-smart-home))

**Instagram’s “AI Content” labels are misfiring again.** The Verge, dated September 4 (12:00 PM UTC), reports users getting the label on photos they did not generate — including Canva Background Remover and light iPhone edits — while the reporter’s own Gemini/C2PA/SynthID images and Firefly edits went untagged. Canva told one creator some assistive tools “were being tagged as generative” and claimed a fix; some Threads users say Background Remover still triggers the label. Meta did not clarify what signals it now scans for. This is a product-behavior report, not a new policy. ([The Verge](https://www.theverge.com/ai-artificial-intelligence/989617/instagram-ai-content-label-confusion))
