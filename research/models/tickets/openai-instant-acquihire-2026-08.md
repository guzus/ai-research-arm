The pattern is the point. OpenAI is repeatedly absorbing the layer
**underneath** the code its agents write — Ona earlier
([[openai-ona-acquisition-2026-06]]), Instant now. Instant's product is
database, auth, permissions and storage for AI-built applications: the
part a coding agent cannot generate because it has to be *operated*.

**Why now.** Codex crossed 20M active users on 2026-08-21, and the
competitive set — Replit's free mode, Vercel's agent tooling, Cursor —
has converged on the same product: describe an app, get a running one.
Whoever owns the backend owns the retained revenue; whoever does not is
sending it to someone else. Buying the team rather than the product is
the cheap way to get there when the value is in the people who built it.

**What this ticket does not establish.** There is one source, no terms,
and no statement from either party. Acqui-hires of this shape routinely
end with the existing hosted service being sunset, which matters to
Instant's current users, and nothing captured here says either way.
Until an @OpenAI post lands, treat the event as reported and the
consequences as unaddressed.
