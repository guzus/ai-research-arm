# arXiv AI Research - 2026-09-11

## Highlights (Top 5 Must-Read)

### 1. T1: Terminal Agent Reinforcement Learning for Long-Horizon Tasks
**Authors**: Junyao Yang, Yucheng Shi, Zhongzhi Li, Ruhan Wang, Zongxia Li, Haitao Mi, Leowei Liang
**arXiv**: [2609.11042](https://arxiv.org/abs/2609.11042)
**TL;DR**: A 122B-total MoE is RL-trained to run a real shell in a cloud sandbox for 300+ tool-call turns, rewarded by each task's own verifier. The recipe is an aggressive warm-start plus a dense process reward (absolute passing-verifier count), TITO construction (train on the exact sampled token IDs with turn-boundary drift repair), and rollout routing replay that records every MoE expert choice and plays it back. Those two cut the train–infer logprob gap from 0.021 to 0.013 with zero token drift in the loss region. The corpus is fully OOD of Terminal-Bench 2.1. Post-training lifts the base from 43.8% to 64.0% resolved; on Long-Horizon Terminal Bench, T1 hits 27.9% and beats GPT-5.4 and GLM-5.1.
**Why it matters**: Long-horizon terminal RL is now a transferable capability, not a leaderboard fit — and the MoE train–serve mismatch was the silent training bug.

### 2. Data Scarcity and Model Sparsity: Mixtures-of-Experts Overfit More to Repeated Data
**Authors**: Atindra Jha, Margaret Li, Jure Leskovec, Percy Liang, Luke Zettlemoyer
**arXiv**: [2609.11917](https://arxiv.org/abs/2609.11917)
**TL;DR**: Repeating training data is the default once unique text runs out. For 80M–1B-active (up to 8.5B total) MoEs it is worse than for dense models, and the damage tracks *total* parameters, not active ones. An 80M dense model can repeat 8× with little loss; MoEs start hurting at 4× and, by 32×, give back every all-unique advantage and lose to dense. Strong masking-based regularization lets MoEs beat dense past 64× repeats, but nothing matches all-unique data. Routing freezes early; expert specialization tracks the overfitting.
**Why it matters**: Sparse-MoE compute efficiency assumes unique data. Under repetition, sparsity is a memorization amplifier unless you regularize it as such.

### 3. SenseNova-U1.5: Towards Native Unified Visual Intelligence
**Authors**: Haiwen Diao, Jiahao Wang, … Ziwei Liu, Dahua Lin
**arXiv**: [2609.11929](https://arxiv.org/abs/2609.11929)
**TL;DR**: An 8B mixture-of-transformers that understands, reasons about, and generates images in one encoder-free, VAE-free stack, at native resolutions up to 4K. Visual interface training uses spatially coherent patch reconstruction; post-training specializes experts for aesthetics, bilingual text, infographics, and editing, then folds them with multi-expert on-policy distillation. Gains land on fidelity, text rendering, composition, multi-reference editing, and interleaved generation, with identity/geometry/unmodified-region preservation. Structured visual instructions transfer from understanding even though generation data barely saw that format. SFT, RL, and OPD training code are to be released.
**Why it matters**: Native unified models no longer need a VAE or a vision encoder as a separate world — understanding can plan the pixels.

### 4. SpecGuard: Inference-Time Backdoor Detection For Free
**Authors**: Rui Wen, Ahmed Salem, Andrew Paverd, Mark Russinovich, Zheng Li
**arXiv**: [2609.11799](https://arxiv.org/abs/2609.11799)
**TL;DR**: Serving already runs speculative decoding: a small draft proposes tokens, the target verifies. When a backdoor fires, the target shifts toward attacker behavior and the clean draft does not, so draft-token acceptance moves. SpecGuard reads that already-paid signal. The paper formalizes when the signal appears and shows that suppressing it also weakens the backdoor. Across backdoor types and model families it catches triggered behavior — including stealthy attacks that input-level filters miss — with no extra generation pass.
**Why it matters**: The accelerator you already bought for latency is a runtime backdoor detector. An attacker who hides from it has to hide the backdoor too.

### 5. Thinking with Looped Flows
**Authors**: Ayhan Suleymanzade, Chanhyuk Lee, Floor Eijkelboom, Nicholas M. Boffi, İsmail İlkan Ceylan, Jinwoo Kim
**arXiv**: [2609.11801](https://arxiv.org/abs/2609.11801)
**TL;DR**: Looped models spend more inference compute by recurring a hidden state, but training usually backprops through one or a few updates, so early steps never learn to help later ones. Looped flows train the recurrence with *local* denoising objectives, then couple the steps by decreasing shared noise so recurrent state still transfers without a long BPTT tape. Inference integrates the probability-flow velocity of the learned denoiser; harder problems get a finer time grid, and different initial noise samples are different valid answers. Across six reasoning benches, including two multi-solution sets: 58.8% on ARC-AGI-1 and 12.2% on ARC-AGI-2, above prior looped SOTA.
**Why it matters**: Test-time compute as a flow — not a transformer unrolled through a credit-assignment wall.
