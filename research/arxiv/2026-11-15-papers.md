## Highlights (Top 5 Must-Read)

### 1. Bait: Mitigating Harmful Agentic Reinforcement Learning via Probing Reward Function
**Authors**: Tiansheng Huang, Ananth Balashankar, Virat Shejwalkar, Santosh Pande, Ling Liu
**arXiv**: https://arxiv.org/abs/2611.16369
**TL;DR**: Agentic RL-as-a-service lets a user supply the environment. For about $20, rounds of toxic-environment RL fully undo the safety alignment of a production model (Inkling), after which the degraded model helps with exploit writing and code-reuse attacks. Bait defends by probing the reward function: it blocks learning from a harmful reward while still learning from a benign agentic one. An adaptive attacker who knows the defense still cannot perfectly subvert it.
**Why it matters**: It is a cheap, API-only jailbreak of the new RL-as-a-service surface, with a defense that does not require trusting the user’s reward.

### 2. DRAMA: Dissecting Attention Redundancy for Accelerating Multimodal Diffusion Large Language Models
**Authors**: Yi-Hsin Hung, Fangfu Liu, Shao-Yuan Lo, Chu-Song Chen
**arXiv**: https://arxiv.org/abs/2611.16345
**TL;DR**: Multimodal dLLMs pay a full bidirectional pass over long visual sequences at every denoising step. Measuring attention along space and time, the authors find mass concentrates on a sparse visual subset and distributions stabilize after an initial formation phase. Training-free Spatial-Redundancy-Aware Visual Token Pruning plus Sufficiency-Guided Adaptive Stopping yields an 18.67× average speedup across six VLM benches with no architecture change, no cache, and competitive accuracy. NeurIPS 2026.
**Why it matters**: It is a measurement-first acceleration of the new dLLM class, not another heuristic cache.

### 3. StateAlign: Internalizing State-Aware Decision-Making for Reliable Multi-Turn Tool Agents via Reinforcement Learning
**Authors**: Zhexi Lu, Subhajit Chaudhury, Tejaswini Pedapati, Keerthiram Murugesan, Lei Yu
**arXiv**: https://arxiv.org/abs/2611.16304
**TL;DR**: Outcome-only tool RL raises task scores while also raising tool hallucination: the agent still calls when it should ask, retrieve, or decline, even after its own reasoning named the missing information. StateAlign builds five task-state conditions and trains with token-level contrasts of the same trace under paired states, on top of outcome rewards. On Qwen3-8B, BFCL v4 multi-turn goes 45.5% → 55.2% and no-tool hallucination on SimpleToolHalluBench falls 62.2% → 56.1% vs outcome-only RL, with the same pattern across three Qwen3 sizes.
**Why it matters**: It treats “when not to call a tool” as a state-matching problem, not a scalar-reward afterthought.

### 4. WorldDraft: If Code Builds the World, Can Video Models Just Render It?
**Authors**: Zhiyu Hou, Wen-Jie Shu, Harold Haodong Chen, Weilin Ruan, Chenfei Liao, Liuzhou Zhang, Disen Lan, Xiaogang Xu, Qi Chen, Ser-Nam Lim
**arXiv**: https://arxiv.org/abs/2611.16217
**TL;DR**: Multimodal coding agents already build 4D worlds in code; the leftover job for video models is to render them. WorldDraft tests that split on 432 paired cases across 48 executable world families, crossing draft granularity with appearance alignment under identical dynamics. Across 12 models, world preservation and visual realization are in tension: richer drafts anchor structure but hurt appearance, and conflicting source cues leak the wrong source in up to 64% of cases. A plug-and-play visual prompt (WorldDraft-Primer) lifts both axes on frozen renderers.
**Why it matters**: It names the failure mode of “video as world model” once geometry is already specified in code.

### 5. JudgeMix: Judge-Guided Mixed-Rollout Data Synthesis for LLM Agents
**Authors**: Cheng-Yu Hsieh, Ting-Yao Hu, Sanjoy Chowdhury, Oncel Tuzel, Raviteja Vemulapalli
**arXiv**: https://arxiv.org/abs/2611.16174
**TL;DR**: Target-aware agent SFT either randomly injects the expert into mixed rollouts or overwrites every step with expert supervision. JudgeMix queries the expert only when a step-wise semantic judge says the target model is struggling, keeping the state distribution on-policy, and reweights expert tokens so already-correct actions are left alone. On AppWorld and AutomationBench it beats existing mixed-rollout and dense-supervision recipes by up to 10 pass@1.
**Why it matters**: It makes expert intervention a judged, on-policy decision instead of a random or uniform overwrite — from the Apple on-device group.
