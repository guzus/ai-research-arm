## Highlights (Top 5 Must-Read)

### 1. MintAct: A Unified Visual Agent for Digital Environments
**Authors**: Mingfei Gao, Rui Tian, Haiming Gang, Bohan Zhai, Le Zhang, Yuanzheng Gong, Di Feng, Ege Özsoy, Kaixin Ma, … Afshin Dehghan
**arXiv**: [2609.22083](https://arxiv.org/abs/2609.22083)
**TL;DR**: One VLM family at 2B / 4B / 8B does UI grounding, multi-step mobile/desktop/web navigation, *and* visual tool use — matching per-domain specialists instead of being a jack of none. The enabling stack is hundreds of concurrent heterogeneous environments plus async RL that keeps the cross-domain mix under control when the env is noisy and the policy is off-policy. Headline number: 48.9 on OSWorld-Verified, SOTA at comparable size.
**Why it matters**: Computer-use is no longer three specialist checkpoints glued together. One recipe, one RL loop, three surfaces.

### 2. RecreationWorld: Scalable and Verifiable Environments for Hybrid Computer-Use Agents
**Authors**: Shuai Bai, Jiayong Deng, … An Yang, Bowen Zhou (32 authors)
**arXiv**: [2609.22000](https://arxiv.org/abs/2609.22000)
**TL;DR**: Real digital work is not "click then code." Hybrid CUAs must decide, mid-task, when to explore a GUI, when to write software, and when to *look* at the result. RecreationWorld gives five OS/web platforms a running reference app as the oracle: recreate it, get execution-grounded reward. RecreationBench is 250 held-out tasks with programmatic *and* visual assertions. GPT-6 Astra leads at 58.1% overall — and passes every programmatic test on 2.8% of tasks. Agents copy static UI more reliably than interactions; the clones stay smaller and more monolithic than the references.
**Why it matters**: The Qwen-line lab just defined the hybrid CUA unit of work — and the frontier still cannot rebuild a working app from watching one.

### 3. CodeMidas: Scaling Agentic Coding RL Environments from Code Itself
**Authors**: Bowen Ye, Lei Li, Shicheng Li, … Lingpeng Kong, Tong Yang, Fuli Luo
**arXiv**: [2609.22068](https://arxiv.org/abs/2609.22068)
**TL;DR**: Issue/commit mining caps how many coding-RL tasks you can mint. CodeMidas treats *implemented functionality* as the only input: agents write behavioral specs, build tests against the original code, then filter by execution and repeated solution rollouts. Result: 5,545 tasks from 3,185 repos, 23 languages, 15 domains. GRPO on MiMo-V2.5 lifts DeepSWE +11.7%, ProgramBench +17%, Terminal-Bench v2.1 +8.5%. More high-quality tasks help; the trained agent explores the repo more and self-verifies more diversely.
**Why it matters**: The scalable substrate for coding-agent RL is the code that already works, not the tickets people filed about it.

### 4. NemotronLabs VoiceChat: An Open Full-duplex Speech-to-Speech Model with Tool Calling
**Authors**: Jagadeesh Balam, Travis Bartley, Edresson Casanova, … Boris Ginsburg, Zhonglei He (49 authors)
**arXiv**: [2609.21967](https://arxiv.org/abs/2609.21967)
**TL;DR**: NVIDIA ships an open full-duplex S2S stack: streaming encoder, decoder-only LM with parallel text and structured-function streams, an RNN-T user-transcript branch, and streaming TTS. One model listens, transcribes, reasons, calls tools, and speaks. Full-Duplex-Bench 1.0: lowest open-weight pause takeover, 100% interrupt takeover, 4.33/5 post-interrupt quality. Bench 1.5: 93% resume after backchannels. VoiceBench 55.1; FDB 3.0 tool-selection F1 82.5% — argument accuracy and end-to-end tool execution still lag.
**Why it matters**: Full-duplex speech, language, and tools in one open checkpoint, without giving up turn-taking.

### 5. Abstention and Noise Filtering: Two Missing Primitives of Softmax Attention
**Authors**: Richard Zhe Wang
**arXiv**: [2609.22005](https://arxiv.org/abs/2609.22005)
**TL;DR**: Value-pathway gates help pretraining, and prior work disagrees on why. The claim: softmax lacks two primitives. *Abstention* — a learned per-head sink so a head can output nothing. *Noise filtering* — a value gate that suppresses superposition interference. Matched 10M–350M runs: abstention's gain shrinks with scale (almost all of the 10M win); filtering's gain grows (most of the 350M win). Best model at every scale has both. Controlled interference confirms the gate removes it; each gate form has a blind spot. Negligible params, KV-cache compatible.
**Why it matters**: "Why gating works" splits by scale. Build both primitives in; do not treat them as one knob.
