## Highlights (Top 5 Must-Read)

### 1. EmbeddingGemma 2: Unified and Efficient Multimodal Representations
**Authors**: Google (Henrique Schechter Vera, Sahil Dua, Jovan Andonov, Sara Smoot, Sebastian Russo et al.)
**arXiv**: [2610.37364](https://arxiv.org/abs/2610.37364)
**TL;DR**: Tuesday's Bolt was a 74B-A9B hybrid VLM squeezed into 24 GB. Today's open drop is smaller and wider: EmbeddingGemma 2 natively embeds text, images, audio, video, and mixes in one space. Simplified per-layer embeddings plus a multi-stage curriculum that progresses by modality and objective. On comprehensive embedding benches it sits on a new Pareto frontier, beating specialists and models two to twelve times larger. Selective encoder loading, adjustable vision-token budgets, truncatable dimensions, and quantized weights. Weights on Hugging Face.
**Why it matters**: The week's other open model was built so a laptop can run the agent. This one is built so every modality shares one vector.

### 2. Scaling Laws for Tool-Use Agents via Controllable Environment Synthesis
**Authors**: Andrew Szot, Samira Abnar, Omar Attia, Abbas Kazerouni, Michael Kirchhof, Cheng-Yu Hsieh, Raviteja Vemulapalli, Alexander Toshev
**arXiv**: [2610.37648](https://arxiv.org/abs/2610.37648)
**TL;DR**: Tuesday's Dabney/Lyle sheet was Chinchilla for actor-critic. This is the sheet for tool-use agents. SynthAPI controls diversity along tools, tasks, and the databases the tools touch. 458,752 tasks, 849 trained models, four sizes. The fitted law: as the data budget grows, scale tool and database diversity, not task count, and raise complexity. Agents trained that way beat prior large-scale tool-use and synthetic-environment recipes on four evaluation benches.
**Why it matters**: Agent data has had recipes. It has not had a law you could spend a data budget against.

### 3. Nemotron-Labs-Diffusion-Uni: Elastic Self-Refining Unified Diffusion LLM
**Authors**: Shufan Li, Hanrong Ye, Greg Heinrich, Yonggan Fu, Haotian Zhang, Sifei Liu, Aditya Grover, Pavlo Molchanov
**arXiv**: [2610.36466](https://arxiv.org/abs/2610.36466)
**TL;DR**: Tuesday's Kuleshov paper was how you *build* a discrete diffusion LM. NVIDIA ships the unified one. Cross-paradigm on-policy distillation pulls autoregressive VLM understanding and continuous-flow generation into a single DLLM. Progressive self-refining corrupts each token across steps instead of jumping clean-to-mask, so inference can commit early and refine. SOTA among unified DLLMs on VQA, multimodal reasoning, grounding, text-to-image, and editing.
**Why it matters**: The DLM recipe now has a unified NVIDIA model that actually does both understand and generate.

### 4. Evolving Agent Teams
**Authors**: Shiyi Cao, Ziming Mao, Dacheng Li, Joseph E. Gonzalez, Ion Stoica
**arXiv**: [2610.36848](https://arxiv.org/abs/2610.36848)
**TL;DR**: Tuesday's RSI Arena handed post-training to the model. This one hands GPU kernel optimization to a team. Sky Lab finds coding agents converge on FlashInfer local optima. Evolving Agent Teams: a supervisor diagnoses the stall and restructures the roster; a persistent filesystem of lessons, history, and artifacts grounds the next team. Matched token budget beats strong coding-agent baselines. Extended budget: 1.2× mean over the production FlashInfer MLA paged-decode kernel from scratch, 36 of 47 FlashInfer-Bench wins. 3.01× vLLM KDA on MI350X; 30.3 tok/s MoE offload for Qwen3.8-Flash-Next on a 48 GB M4 Pro.
**Why it matters**: Autonomous kernel work is no longer a demo. The production kernel is the baseline, and the team beat it.

### 5. Gym-Anything-RT: Scaling Real-Time Environments for Vision-Language Agents
**Authors**: Pranjal Aggarwal, Sean Welleck
**arXiv**: [2610.37567](https://arxiv.org/abs/2610.37567)
**TL;DR**: Tuesday asked whether agents can post-train. This asks whether they can act while the world moves. An agentic pipeline writes 100 visual minigames covering six real-time skills; the same game can pause or run live. GPT-6 Astra (xHigh) hits 9.0% when the clock runs and 75.0% when it pauses. Given code, frontier agents write around the clock instead of perceiving in it. The suite is public.
**Why it matters**: The capability gap is the clock, not the puzzle. Desktop agents are not real-time agents.
