## Highlights (Top 5 Must-Read)

### 1. Coding Agent Memory Post-Training II: Unlocking the Memory Potential of Pre-trained File Operations for Long-Horizon Tasks via On-Policy Distillation
**Authors**: Lirui Luo, Kelong Mao, Xinwei Yang, Rongqing Li, Luyu Chen, Kieran Wong, Yudong Guo, Xinrui Wang, Jiayin Zhu, Gu Simiu, Sulong Xu, Cong Fang
**arXiv**: https://arxiv.org/abs/2611.14009
**TL;DR**: On-policy distillation of agent memory usually fails because the teacher has never used the memory tools and the student almost never emits them. CAMP-II instead gives the policy ordinary Bash plus an episode-persistent workspace, so write/read/search of files *is* the memory interface, and trains one policy jointly on Shop, Coding, AutoResearch, General and Visual with fully asynchronous OPD from a frozen teacher that already has a file-ops prior. On CAMG-II it gets 2.97× the gain of the strongest OPD baseline; the same memory behavior lifts Terminal-Bench 2.1 and SWE-Bench Pro V2.
**Why it matters**: It turns long-horizon memory from a bolted-on protocol into a pretraining-native file skill, and the transfer to two external coding benches is the evidence that it is not gym-specific.

### 2. BioXArena-Pro: a research-grade benchmark for autonomous biomedical machine learning agents
**Authors**: Loka Li, Duzhen Zhang, Xingbo Du, Leonard Song, Kun Zhang, Le Song
**arXiv**: https://arxiv.org/abs/2611.13994
**TL;DR**: Coding agents are being sold as autonomous biomedical model-builders, but existing benches are small, saturated, or leakable. BioXArena-Pro rebuilds 64 published modelling studies across eight domains and holds out whole biological units (species, cohorts) on most tasks. Across 22 agent configurations the best scores 55.1/100; the scaffold matters almost as much as the model. Where the published recipe still applies, agents tie the original methods; on rebuilt tasks they lead by 8.2 points by adapting. Forbidding pretrained biological foundation models drops the strongest agent 9 points on the tasks that used them.
**Why it matters**: It is a leak-resistant, research-grade agent bench from a lab that already ships causal ML, and it shows that scaffold and foundation-model reuse — not just the LLM — set the score.

### 3. Understanding Mixture-of-Experts Language Models Beyond Expert Boundaries
**Authors**: Zhenhong Zhou, Mao Zheng, Mingyang Song, Qiankun Li, Kun Wang, Junfeng Fang
**arXiv**: https://arxiv.org/abs/2611.13975
**TL;DR**: Expert-level routing still disagrees about whether MoE experts specialize by domain or by token identity. Routing-Aware Magnitude Profiling looks one level down: domain-specialized neuron sets overlap 58–74% within a domain and 15–24% across domains. Neuron importance keeps reorganizing through pre-training even while expert-level rankings look stable; post-training mostly freezes the neurons. RAMPr, a pruning rule built on that measure, keeps 91–98% of full-model average performance at 75% neuron retention, and at 50% retention cuts resident GPU memory 36–43% while raising batched prefill 17–39%.
**Why it matters**: It resolves the MoE-specialization argument at the unit that actually computes, and turns that unit into a practical compression knob.

### 4. ZoomGain: Mining Global-to-Zoom Perception Gaps for Fine-Grained Visual Supervision
**Authors**: Haozhan Shen, Liangbo He, Jun Lan, Huijia Zhu, Weiqiang Wang, Tiancheng Zhao, Jianwei Yin
**arXiv**: https://arxiv.org/abs/2611.14076
**TL;DR**: VLMs miss fine-grained evidence in the full image but often see it once the region is zoomed. ZoomGain builds questions from that gap, multi-model-verifies answers on the zoomed crop, and rejects items solvable from language priors. The resulting 1,000-question bilingual ZoomGainBench tops out at 61.08 across 28 VLMs. Training on only 9K ZoomGain samples lets 4B/9B models beat several hundred-billion-parameter systems on perception benches; the 9B hits 90.25 on HR-Bench 4K.
**Why it matters**: It is a scalable supervision recipe for the exact failure mode of current VLMs — not seeing what they could see if they looked closer — without a human QA editor.

### 5. From Attack Surface to Defense Architecture: Compositional Security for Agentic Coding Harnesses
**Authors**: Simon Hegelich, Bardh Prenkaj, Habiba Sarhan, Morteza Shahrezaye, Kolja Hegelich, Christian Montag, Ralf Schneider, Erik Cambria
**arXiv**: https://arxiv.org/abs/2611.13960
**TL;DR**: A coding harness with bash, curl and a filesystem is a Living-off-the-Land platform the moment retrieved content carries instructions. ActiveSecHarness separates intelligence from authority: HMAC capability tokens across four trust rings, a 2D trust×sensitivity taint lattice, a workspace provenance ledger, and microsecond Ring-0 OS guards. On 252 fixtures a live qwen3:4b judge refuses 98.3% of *benign* work at 142 ms; Ring 0 gets ABR=1.000 and FPR=0.000 in 12.7 µs (11,200× faster). Coarse Boolean taint blocks 83.3% of benign workflows; the 2D lattice does not.
**Why it matters**: It treats coding-agent security as a permission architecture, not a smarter model, and shows why LLM-as-judge guardrails are both slow and hostile to real work.
