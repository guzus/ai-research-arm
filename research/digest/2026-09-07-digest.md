## Research Highlights

The arXiv CS.AI and CS.LG feeds are still on the weekend `skipDays` build, so the curated set below is the 2026-09-06 collection.

- **Principia: Relational Physics Tests for Video Models** (arXiv:2609.04200) — scores Newtonian consistency between paired objects using a calibration-free image-space violation score. Across thousands of generations from six SOTA video models, none exceed 0.42 on Principia while all sit near 0.8 on VBench. The best VLM detects relational violations 67% of the time; most are near chance.
- **Clean Engineering, Unstable Measurement** (arXiv:2609.04198) — two preregistered LLM-as-judge campaigns (52,988 attempts) never cleared instrument validation: same-window rank Spearman 0.400 against a required 0.90, next-day byte-identical replay 0.78 against 0.99. Waiting, switching providers, and metric substitution did not repair it. On a shared endpoint a model name is not a frozen instrument.
- **Legibility is Not Interpretability** (arXiv:2609.04194, COLM 2026) — operationalizes chain-of-thought step importance as Monte Carlo advantage. Capable LLM judges beat a prevalence baseline but sit well below the noise ceiling, meaning process reward models and CoT monitors are supervising a narrative that only loosely tracks which steps move the answer.
- **Efficient Test-Time Adaptation through Human-AI Interaction** (arXiv:2609.04141) — TAHI treats cross-session user edits as the missing training signal and crystallizes each user's criteria into an evolving rubric. Across 600 writing and visual-creation tasks for 30 people, solo success rises 4.5–20.9% within tens of tasks, and the rubric catches 16.0–22.3% more failures than LM-only or human-only labels.
- **Terminal-Universe** (arXiv:2609.04148) — replays recorded file operations to turn frozen agent traces back into live terminals, yielding 37.3k task-sufficient environments from public traces. SFT of Qwen3.5-27B gains +11.9 on Terminal-Bench 2.1 and +13.8 on EvoCode-Bench v2 MT@4.
- Also notable: **SWE-Gate** (arXiv:2609.04167) finds 221 of 644 functionally-passing repo patches fail the review spec, and **PatchBench** (arXiv:2609.04075) reports PoC-only scoring inflates agent solve rates 1.83× across 11 agents — two independent results arguing that current agent coding benchmarks grade the wrong thing.
- A circulating preprint, "Repo-To-Skill," claims MLE-bench rises from 31.11% to 72.89% on the same model at the same task budget using a 5,353-skill library mined from 1,000 ML repositories. Treat it as an unreplicated single-source claim: skills distilled from ML repos could plausibly encode solution recipes for MLE-bench's Kaggle-derived tasks, and no contamination audit has been posted (Twitter).
