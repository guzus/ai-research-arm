- [condense-json 1.0](https://simonwillison.net/2026/Aug/2/condense-json/) - 2026-08-02 22:19 UTC
  > A 1.0 release of his year-and-a-half-old Python library, which rewrites
  > strings and substrings that appear in a supplied `replacements` object into
  > a compact `{"$r": [...]}` form, reversible via `uncondense_json()`. The
  > motivating use case is LLM-adjacent: shrinking the duplicated prompt text
  > stored in the SQLite logs written by his `llm` CLI (PR #1586). Tagged
  > json / projects / python / llm.
