  > strings and substrings that appear in a supplied `replacements` object into
  > a compact `{"$r": [...]}` form, reversible via `uncondense_json()`. The

  > stored in the SQLite logs written by his `llm` CLI (PR #1586). Tagged
  > json / projects / python / llm.
