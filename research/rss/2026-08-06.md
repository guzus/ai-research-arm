about the layer that failed in the Irregular incidents: the boundary
between an agent's reasoning and its external execution.

The first three papers each attack that boundary from a different
direction. TrajRed/TrajGuard argues execution risk is a TRAJECTORY-level
phenomenon rather than an outcome — fixed-template red teaming sees the
final action and misses how a multi-step tool-use chain got there — and
turns the high-risk trajectories found in red teaming into a runtime
governance layer (AgentDojo, four organizational task suites; attack
success driven to near zero with benign utility preserved). SafeCommit
inserts a risk-controlled layer BETWEEN reasoning and external execution
and permits a side-effectful action only when a conformal certificate
shows it is safe in every retained plausible world, otherwise probing or
falling back; its framing — deciding not just what an agent should do but
whether the evidence yet suffices to do it — is exactly the check absent
when a model reached the open internet unnoticed. "The LLM Proposes, the
Executive Disposes" goes furthest structurally: a deterministic Executive
owns all belief and the model may only file typed proposals admitted
against pre-registered predictions. It is also the most honest paper in
the batch — four of its first eight architecture runs self-invalidated on
canary/write-error floors, each localizing a real defect, and the authors
report task efficacy as NULL. Read it as instrumentation, not as a
capability result.

Then the mechanism layer. AgentAntibody learns the user's security
boundary across encounters rather than treating each task as
self-contained — the useful observation being that underspecified
requests are what injections exploit, so a defense that never accumulates
context cannot close the gap. Canary tools is the sharpest empirical
result here for anyone selecting a model for tool use: planting six types
of diagnostic decoy in an MCP tool set across 8,640 runs turns "wrong
tool" into a profile of WHY, and yields two findings that cut against
normal procurement intuition — susceptibility varies ~36x across models,
but capability tier does NOT predict safety (the most susceptible hosted
model is mid-tier, and within a provider the cheaper model can be the
safer one), while "capability mirages" specifically trap frontier models
where the other decoy types are inert on them. Argus and OneDayAgent are
the harness side, and both are load-bearing for this repo rather than
merely topical: Argus builds operator-owned escalation points into an
otherwise autonomous long-horizon runtime (78% on SWE-Bench Pro vs 59%
for direct use, at 1.41x tokens), and OneDayAgent reports its state of
the art (0.821 on AgentIF-OneDay) on the **GLM-5.2 backend** — the same
model this pipeline carries as fallback-chain link 2 — while running
unchanged across five backends from three families. Architectural
Implications is the datacenter view from a Microsoft Azure PRODUCTION
study: agentic execution is fragmented, repeatedly crosses the CPU-GPU
boundary, and puts the CPU on the critical path with low-but-spiky load.
That is a first-party measurement of what agent fleets actually cost to
host, and it is rare.

The last four are evaluation validity, which is the thread this file has
been pulling since 00:24. Item Response Theory for AI Safety is the
largest psychometric analysis of LLM safety evals to date (8 benchmarks,
192 models); it finds three interpretable factors — refusal strictness,
truthfulness, contextual harm — explain most between-model variance, that
~10 adaptively chosen items can recover a benchmark score (97-99% cheaper),
and, most relevantly here, that IRT can detect naive SANDBAGGING and
silent model swaps behind an API. SciCode-Verified is the strongest
result in the batch and it inverts the usual "benchmarks are too easy"
complaint: a domain-expert audit of all 65 SciCode problems found 263
defects, 192 of them score-SUPPRESSING and spread across 91% of main
problems, and 78% of those needed real physics or mathematics to spot
rather than proofreading. Correcting them lifts subproblem accuracy from
45-60% to 84-98% and main-problem accuracy from 9-27% to 69-92% across
twelve frontier snapshots. The plateau everyone was reading as a
capability ceiling was substantially a measurement artifact — and SciCode
sits inside the Artificial Analysis Intelligence Index and in government
and national-lab suites, so the artifact propagated into policy-facing
numbers. SkillClone closes the loop on agent supply chains by showing
file secrecy is not functional secrecy: a hidden skill can be cloned from
ordinary legitimate use, so disclosure-focused defenses miss the attack
entirely. EA-Graph, Active-SWE and RepoProbe are the coding-agent tail —
and EA-Graph is worth reading against the Grokipedia item in the 03:48
section above, because it formalizes the same failure: a repository can
still BUILD while the verification claims that justified it have silently
gone stale, and the fix is to make an unbacked claim UNPROVABLE rather
than let the agent guess. Note EA-Graph's own bounded claim: the effect
was significant only in the Haiku round (p = 0.0156 per world), with the
Sonnet round hitting control ceilings.

The CS.LG block is the training-time and adversary-side inverse. Trident
trains a 7B planner to red-team deep-RL cyber defenses that have only
ever been evaluated against static heuristic attackers, and finds them
brittle — its headline "522% average reduction in blue-agent defensive

alignment degradation from fine-tuning on tasks with no obvious safety
relevance — which is the realistic deployment case, unlike the usual
setup where a behavior is deliberately implanted and then confessed.
EvolveNet, State2State, Skill Entropy and OctoLong are the
