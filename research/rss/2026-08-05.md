### 🧠 Expert Commentary

#### Simon Willison
- [New release of LLM adds support for reasoning traces, OpenAI Responses, server-side tools, and smarter logging](https://simonwillison.net/2026/Aug/4/new-release-of-llm/) - 2026-08-04 23:58 UTC
  > Willison's own writeup of LLM 0.32, which he calls "the most
  > significant new version of LLM since the initial launch of the
  > project." Four changes he foregrounds: visible reasoning traces,
  > server-side provider tools, redesigned content-addressable SQLite
  > logs, and OpenAI Responses API support. Note what this is — a
  > maintainer's release announcement for his own CLI/library, not a
  > model release or a benchmark claim. The interesting bit for anyone
  > building on it is the logging redesign: content-addressable storage
  > changes how prompts/responses are deduplicated on disk.

- [llm-anthropic 0.26](https://simonwillison.net/2026/Aug/4/llm-anthropic/) - 2026-08-04 22:00 UTC
  > Companion plugin release riding on the LLM 0.32 features. Adds three
  > model ids — `claude-fable-5`, `claude-sonnet-5`, `claude-opus-5`
  > (#75, #76) — and exposes Anthropic's server-side tools (WebSearch,
  > WebFetch, CodeExecution, AnthropicMCP) through LLM's tool interface.
  > Worth flagging because "server-side tools" here means the provider
  > runs them, so they are not the same trust boundary as local tools.

- [llm 0.32](https://simonwillison.net/2026/Aug/4/llm/) - 2026-08-04 17:15 UTC
  > The bare release note for the same version, pointing at the detailed
  > blog post above. Listed separately because it is a distinct feed
  > entry, not additional reporting.
