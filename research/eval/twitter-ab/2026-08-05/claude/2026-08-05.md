      <p><strong>Evidence:</strong> The design is the interesting part. Prime Agent treats context as a variable and sub-agent delegation as function calls inside a REPL; the model can programmatically search its own history, launch persistent sub-agents, and store state outside the active context window. A "Continual Harness" layer lets the agent create, read, update and delete its own prompts, skills, memory and sub-agents from its own trajectory. @mark_k described ARC-AGI-3 as "completely saturated," and @kimmonismus confirmed the harness is open-source and model-agnostic, achieving its best result with Opus 5.</p>
      <p><strong>Counter / contradicting:</strong> The strongest counter-hypothesis is that ARC-AGI-3 has been measuring scaffolding quality, not model generality — and OpenAI conceded exactly this a week earlier. On 2026-07-29 it published that after GPT-5.6 Sol underperformed on ARC-AGI-3, investigation showed "the harness was not letting it remember what it had learned," and enabling two API settings tripled its score using 6x fewer output tokens. If two config flags triple a score, a purpose-built continual-memory harness clearing 95% is a predictable engineering result rather than a capability jump; @scaling01 made the same argument bluntly, that the benchmark's designers "didn't want to acknowledge the existence of harnesses." The partial defence, from @teortaxesTex, is that only the strongest agentic models get a large uplift from a general harness, which is the behaviour you would want. Both can be true: the number is real and the framing that it demonstrates a leap in reasoning is not supported. Absent an ARC Prize verified score on the semi-private set, treat 95.5% as a developer-reported figure.</p>
