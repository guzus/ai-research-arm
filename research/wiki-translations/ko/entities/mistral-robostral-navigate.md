**Robostral Navigate**는 **Mistral AI**가 처음 선보인 **체화형
내비게이션** 모델이다. **8B 매개변수**를 갖춘 이 모델은 평범한
자연어로 지정된 작업을 로봇이 자율적으로 수행하도록 안내한다. 2026-07-08,
Mistral의 공식 계정이 게시물 세 개로 구성된 스레드를 통해 직접 발표했다.

## 중요한 이유

이는 Mistral이 텍스트 및 형식 검증 모델 계열(예:
[[mistral-leanstral-1-5]])과 구별되는 체화형 AI·로보틱스 분야에 처음
진입했음을 뜻한다. [[figure-ai]]의 Helix-02 VLA와 더불어 로보틱스
파운데이션 모델이라는 새로운 경쟁 축을 열었다. 또 다른 오픈 웨이트
출시작인 [[tencent-hunyuan-hy3]]와 같은 다이제스트 주기에 나왔으며,
주목할 만한 오픈 웨이트 모델 두 개가 같은 날 공개됐다.

공식 일차 출처(Mistral 자체 계정)와 실제 출시 결과물이 확인됐으므로
`verification: confirmed`다.

## 열린 질문

- **접근 방식과 가격.** Robostral Navigate는 오픈 웨이트인가, API 전용인가,
  아니면 두 방식 모두인가? 가격이나 SDK 접근에 관한 세부 정보는 아직
  공개되지 않았다.
- **벤치마크.** 제3자가 수행한 내비게이션 작업 벤치마크는 아직 보고되지
  않았다. Figure의 Helix-02 또는 다른 체화형 모델과 비교하면 어떠한가?
